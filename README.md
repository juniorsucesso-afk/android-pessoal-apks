# APKs pessoais para Android

Downloads diretos, sem login e sem expiração programada:

- [Startup Company 0.1.0 — 223 MB](https://github.com/juniorsucesso-afk/android-pessoal-apks/releases/download/v0.1.1/StartupCompany-Personal-Android-0.1.0.apk)
- [Prison Architect 0.1.1 — 603 MB](https://github.com/juniorsucesso-afk/android-pessoal-apks/releases/download/v0.1.1/PrisonArchitect-Pessoal-Android-0.1.1.apk)
- [Project Hospital 0.1.1 — 589 MB](https://github.com/juniorsucesso-afk/android-pessoal-apks/releases/download/v0.1.1/ProjectHospital-Pessoal-Android-0.1.1.apk)

Abra o APK baixado no Android para instalar. Nos protótipos de Prison Architect e Project Hospital, abra o aplicativo e use **Preparar e instalar → Jogar**.

Prison Architect e Project Hospital são protótipos experimentais com Winlator/Wine/Box64 incorporado, destinados a Android ARM64. A compilação foi verificada; a execução e o desempenho no Galaxy S25 ainda precisam ser testados no aparelho. Não são ports Android nativos nem versões oficiais. Autenticação legítima da plataforma, se exigida pelo título, continua necessária pelo cliente integrado. Nenhuma senha ou token de conta foi copiado do computador.

Startup Company usa WebView e inclui uma cópia independente da partida DataTec. Os dados do celular ficam separados dos saves do Windows. Desinstalar ou limpar os dados de qualquer aplicativo remove os saves locais correspondentes.
